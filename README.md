UR5e Safety & Security Labs

Industrial Safety, Cybersecurity, Risk Assessment & AI Safety

A collection of academic laboratory studies exploring industrial safety and cybersecurity concepts through the Universal Robots UR5e collaborative robot.

This repository documents seven laboratory exercises covering safety architecture, industrial network security, risk assessment, secure remote access, vulnerability management, incident response, and AI safety.

The studies are based on technical documentation, security standards, and illustrative scenarios.

Project Overview

The main objective is to examine how industrial safety and cybersecurity principles can be applied to a collaborative robotic system.

The Universal Robots UR5e serves as the reference platform for analyzing potential hazards, identifying cybersecurity risks, and proposing appropriate protective measures.

The project focuses on:

* Industrial robot safety and risk assessment
* IEC 62443 cybersecurity principles
* Network segmentation and secure remote access
* Vulnerability and patch management
* Cybersecurity incident response
* AI-assisted automation and fail-safe decision-making

Laboratory Contents

Lab	Topic	Main Focus
01	Safety Architecture	Safety functions, emergency stops, safe states, and safety-related control systems
02	IEC 62443 Mini Workshop	Industrial network segmentation, security zones, and conduits
03	Threat & Risk Analysis	Cybersecurity threat scenarios, risk scoring, and prioritization
04	Secure Remote Access	Secure connectivity, authentication, and access control
05	SBOM / CVE / Patch Management	Software component inventory, vulnerability assessment, and patch decisions
06	CRA Incident Simulation	Incident detection, evidence preservation, response, and reporting
07	AI Safety Challenge	AI-related risks, human oversight, and fail-safe decision-making

Reference System

Manufacturer: Universal Robots
Model: UR5e
Robot Type: Six-axis collaborative industrial robot
Programming Environment: PolyScope

The UR5e was selected because its documented safety functions, configurable control system, and industrial communication capabilities provide a useful foundation for studying safety and cybersecurity.

Some laboratory scenarios introduce additional components or proposed improvements, such as VPN-based remote access, centralized security monitoring, and AI-assisted visual inspection.

These are conceptual designs and should not be interpreted as standard features of the robot.

Project Scope

This repository contains educational and documentation-based analyses.

The laboratory exercises were not performed on a physical UR5e robot. Risk scores, network architectures, cybersecurity scenarios, and proposed AI integrations are illustrative.

The work does not constitute an official safety certification, penetration test, regulatory compliance assessment, or validation of a deployed industrial system.
